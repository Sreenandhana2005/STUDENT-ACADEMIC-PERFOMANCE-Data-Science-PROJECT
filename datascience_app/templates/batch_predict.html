Required CSV Format

Your CSV should include these columns (at minimum):

Column Name Description Example Value Required
Age_at_enrollment Student's age at enrollment 20 ✓ Required
Admission grade Admission test score (0-200) 150 ✓ Required
Previous qualification (grade) Previous course grade (0-200) 140 ✓ Required
Tuition fees up to date 1 = Yes, 0 = No 1 ✓ Required
Curricular units 1st sem (approved) Units passed in 1st semester 5 ✓ Recommended
Curricular units 2nd sem (approved) Units passed in 2nd semester 4 ✓ Recommended
Course Course code number 9000 ✓ Recommended
Scholarship holder 1 = Yes, 0 = No 0 ✓ Recommended
Note: Missing columns will be filled with default values (0). The more complete your data, the more accurate the predictions will be.

Output File Columns

Your downloaded file will include these additional columns:

Predicted_Status

Predicted outcome: Dropout, Graduate, or Enrolled

Churn_Risk_Score

Risk score from 0-100% (higher = more likely to dropout)

Risk_Level

Risk category: Low, Medium, or High
